## Usage notes

`onReorder` receives the items in their new order, so `onReorder={setItems}` is enough for local state. The raw React
Aria reorder event is passed as the second argument, and `reorderItems(items, event)` is exported for use in your own
state logic. Keyboard users focus a row, press the right arrow to reach its handle, press Enter, move with the arrow
keys and press Enter again to drop.
